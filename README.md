# Python Console Chat Application
 
A simple multi-user chat application built with Python sockets.

## Author
Франсиско Розарио Диого (Francisco Rosario Diogo)

## Enhanced Features

### ✨ NEW GUI Enhancements:
- **Live Online Users List** - See who's online in real-time
- **Rich Text Formatting** - Use *bold*, _italic_, ~underline~ formatting
- **Enhanced Emoji Picker** - Categorized emojis with easy picker
- **Theme Switcher** - Toggle between light/dark themes
- **Clickable Links** - URLs in messages are clickable
- **@Mentions** - Mention users with @username
- **Character Counter** - Real-time message length counter
- **Search Users** - Search/filter online users
- **📎 File Sharing** - Send and receive files (images, PDFs, documents, etc.)

### 🎭 Emoji Support
- Use text codes like :) :( :D <3 etc.
- Enhanced emoji picker with categories
- Over 200+ emojis organized by category

### 📝 Message Formatting
- **Bold:** `*text*`
- **Italic:** `_text_`
- **Underline:** `~text~`
- **Mention:** `@username`
- **Links:** Auto-detected and clickable

### 📎 File Sharing Features
- **Send any file type** - Images, PDFs, documents, archives, etc.
- **10MB file size limit**
- **Auto-save received files** to "received_files" folder
- **File type icons** for easy identification
- **Click to open** received files
- **Visual progress indicator** during upload
