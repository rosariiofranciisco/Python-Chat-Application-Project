# Python Console Chat Application
 
A simple multi-user chat application built with Python sockets.

## Author
Франсиско Розарио Диого (Francisco Rosario Diogo)

## Features
- Real-time messaging
- Multiple users support
- Nickname system
- Timestamped messages
- Graceful connection handling
- 🎭 **Emoji Support** - Use text codes like :) :( :D <3 etc.

## How to Run

1. **Start the Server:**
   <!-- In the terminal run the following commands -->
   python server.py

2. **Connect Clients:**
   <!-- Each time we need to connect new user, in the new terminal we run the following commands -->
   <!-- There is a possibility to have more than one user interface,
      by running the same "python gui_client.py" command in new terminal-->

   for GUI Client (with user interface): 
      python gui_client.py

   or

   for Console Client (without user interface): 
      python client.py
